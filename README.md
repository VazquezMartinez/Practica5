# Mazo de Cartas

Programa desarrollado en Java que simula el manejo de un mazo
de 52 cartas.

## Características

- Creación de un mazo de 52 cartas.
- Cuatro figuras mediante un enum.
- Barajado del mazo.
- Repartición de cartas a jugadores.
- Administración de cartas no repartidas.
- Regreso de cartas al mazo.
- Pruebas automatizadas con JUnit.
- Documentación mediante Javadoc.

## Ejecución

Ejecutar la clase:

Juego.java

También se pueden ejecutar las pruebas mediante:

mvn test

## Estructura

- Carta: representa una carta.
- Figura: enum con las cuatro figuras.
- Mazo: administra las cartas.
- Jugador: administra las cartas de cada jugador.
- Juego: contiene el método main().
- Test: contiene las pruebas automatizadas.
